# Hi, I'm Ariff 👋

I build practical web apps for everyday problems: personal finance, community projects and household tools. Most of them are made for people in Malaysia, and many are in Bahasa Melayu.

Right now I'm learning AI-assisted development, self-hosting and better ways to organise knowledge. I'm open to collaborating on web projects.
