# Global Preferences

## Commits, pull requests, and comments

- Do not add any Claude or Anthropic branding to commit messages, pull request
  titles or descriptions, code comments, or GitHub comments.
- This includes `Co-Authored-By` trailers, session links, "Generated with ..."
  lines, and footers of any kind that name the assistant or its vendor.
- Write commit messages as plain, descriptive summaries of the change only.
